# e-plantShopping

A React-based e-plant shopping application — **Paradise Nursery** — for browsing and purchasing houseplants online.

## Project Name

**e-plantShopping** (Paradise Nursery)

## Overview

Paradise Nursery is a full-featured plant shopping web application built with React and Redux Toolkit. Browse beautiful houseplants organized by category, add them to your cart, and manage your order with ease.

## Features

- 🌿 Paradise Nursery landing page with company name and Get Started button
- 🛒 Shopping cart powered by Redux Toolkit
- 🌱 3+ plant categories with 6+ plants each
- ➕➖ Quantity controls and item removal
- 💰 Dynamic total price calculation

## Tech Stack

- React 18
- Redux Toolkit
- Vite
- CSS3
